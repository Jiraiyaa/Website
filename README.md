# Blackframe Studio Website

Premium static landing page for Blackframe Studio, a website design service for modern businesses.

## What this site includes

- Responsive one-page landing page
- Premium black/cream/gold visual system
- Hero concept carousel using local image assets
- Services, industries, concept work, process, pricing, and contact sections
- SEO metadata, Open Graph/Twitter previews, canonical URL, and structured data
- Accessible mobile menu, skip link, labels, reduced-motion support, and semantic sections
- Contact form powered by FormSubmit
- Direct email CTA

## Deployment

This repo is ready for GitHub Pages as a static site.

Recommended GitHub Pages settings:

1. Open repository settings.
2. Go to **Pages**.
3. Set source to `Deploy from a branch`.
4. Select branch `main` and folder `/root`.
5. Save.

Expected GitHub Pages URL:

```txt
https://jiraiyaa.github.io/Website/
```

If you use a custom domain later, update these files:

- `index.html` canonical URL
- `index.html` Open Graph URL/image paths
- `robots.txt` sitemap URL
- `sitemap.xml` page URL
